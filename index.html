云笺

离线 AI 笔记本 Android 工程：本地记录 + 端侧 / 云端双通道对话，对话可抽取为笔记，问答依据本地笔记回答。

versionName 0.2.0 Android minSdk 24 / targetSdk 34 arm64-v8a · x86_64 Kotlin + Compose
查看源码仓库 构建说明

功能亮点

记录、对话、抽取、检索闭环，数据落在本机。

📝

本地记录

笔记列表、正文编辑、文件夹分类、修订历史与回收站，全部存于本机 Room 数据库。

🔀

双通道对话

端侧内置 GGUF 模型整段推理；云端走 OpenAI 兼容接口，支持 SSE 流式与思维链，通道选择持久化。

🗂️

对话抽取入库

按 JSON 契约抽取标题 / 正文 / 标签 / 人物 / 地点 / 情绪 / 待办，气泡标注「📝 已存入笔记」。

🔎

读库问答

先检索本地笔记标题与正文作为证据，只依据记录回答、不编造，气泡标注「📎 依据」。

💬

会话落库回看

多轮历史携带到模型请求，消息持久化，可随时回看上下文。

🧩

可移植内容形态

多内容类型数据模型、底部多 Tab 导航、聊天壳参数 / 预设 / 用量与视觉主题。

技术栈

纯 Kotlin / Compose 界面，Room 持久化，NDK 桥接 llama.cpp。

模块结构

源码位于 app/src/main/。

app/src/main/
├── java/com/yunke/ainote/
│   ├── ai/          NoteExtractor（对话抽取为笔记，JSON 契约）
│   ├── data/       Room 实体 / DAO / Repository / 数据类型
│   ├── llm/        LlmEngine（JNI 桥）、ModelManager（模型状态/内置拷贝/加载）
│   ├── remote/     RemoteChatClient（云端非流式 + SSE 流式）
│   ├── settings/    ChatParams / Presets / SettingsStore / UsageStore / 通道枚举
│   └── ui/         Compose 屏幕、消息模型、主题、导航
├── cpp/            llm_jni.cpp（JNI 加载/采样/释放）、CMakeLists.txt
├── res/            图标与资源
└── assets/models/  内置 GGUF 模型（不入库，见构建说明）

构建与外部依赖

仓库按 .gitignore 排除了体积过大或第三方的内容，clone 后需补齐两项才可编译 native。

  • llama.cpp 源码：放到 third_party/llama.cpp/（与 :app 平级），版本 v1.0.0；CMake 通过 add_subdirectory 静态编入。
  • 内置模型权重：放到 app/src/main/assets/models/Qwen3-0.6B-Q4_0.gguf（Qwen3-0.6B-Q4_0，Apache-2.0，约 364MB）；首启由 ModelManager.ensureBuiltin() 拷贝到私有目录后加载。
JDK / SDKJDK 21；Android SDK 34；build-tools 34.0.0
NDK / CMakeNDK 26.1.10909125；CMake 3.22.1
编译命令./gradlew assembleDebug（Windows：gradlew.bat assembleDebug）
路径注意工程路径不要含中文 / 空格 / 括号，否则 CMake/Ninja 配置 native 会失败。
